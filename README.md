# C++ OOP University Coursework Archive

This repository is an archive of C++ OOP university coursework.

## Repository Structure

The project is organized into task sets, each containing multiple individual tasks:

- [Task Set 1](src/task-set-1/): Introduction to OOP
- [Task Set 2](src/task-set-2/): Objects and Classes
- [Task Set 3](src/task-set-3/): Class Composition
- [Task Set 4](src/task-set-4/): Inheritance
- [Task Set 5](src/task-set-5/): Polymorphism
- [Task Set 6](src/task-set-6/): Templates and Exceptions
- [Task Set 7](src/task-set-7/): Static Variables and Methods
- [Task Set 8](src/task-set-8/): Pointers to Functions
- [Task Set 9](src/task-set-9/): Standard Template Library

## Building the Project

1.  **Configure the project**:
    Choose a preset (either `clang-debug` or `clang-release`):
    ```bash
    cmake --preset clang-debug
    ```

2.  **Build the project**:
    ```bash
    cmake --build --preset clang-debug
    ```
