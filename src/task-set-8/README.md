# Task Set 8: Pointers to Functions

### Task 1
Create an employee class that stores the following data: name, surname, specialty, age, experience, salary.
Write a program in which the user, before entering data about the employee, can choose the order of input and output of data about the employee.
Use pointers to functions to perform the task.

---

### Task 2
We have a personnel class that stores an array of 10 employee class objects.
Implement filtering method that would have a pointer to a function argument for selecting employee groups by age:
* young (age 18 to 30);
* middle-aged (31-50);
* elderly (51-70);
* old age (71 and older);

---
