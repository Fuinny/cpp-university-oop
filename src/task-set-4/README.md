# Task Set 4: Inheritance

### Task 1
Create two classes: Student and Person.
Person has the following variables: first name, last name, age.
Student has all personal data and additional variables related to his studies: ID, names of study subjects, average grades.

---

### Task 2
Write a program that would allow to calculate the length of a vector in two-dimensional space and in three-dimensional space, when the coordinates of those vectors are given.
Implement vectors in two classes, linked by a class inheritance relationship.

---

### Task 3
Write a program that would allow to calculate the volume of a cylinder, when the radius of the base and the height are given.
To perform the task, describe two classes Circle (base class) and Cylinder (derived class).
In the Circle class, the area of ​​the circle will be calculated, and in the Cylinder class, the volume will be calculated - the area of ​​the circle multiplied by the height of the cylinder.

---

### Task 4
Describe three classes, linked by inheritance to the corresponding variables:

* GeometricShape:
    * perimeter
    * area
* Rectangle:
    * length
    * width
    * perimeter
    * area
* RectangularCuboid:
    * length
    * width
    * height
    * perimeter
    * area
    * volume

Implement methods in the corresponding classes to calculate the perimeter, area, and volume.
Also implement the constructors so that data can be assigned during object creation.
Create objects of these classes using constructors and output all the information to the screen.
