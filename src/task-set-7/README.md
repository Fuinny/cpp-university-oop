# Task Set 7: Static Variables and Methods

### Task 1
Create a class of products containing variables for the name of the products, the quantity, the unit price, the price of the quantity and the sum of the prices of all products.
The total sum of the prices of the products is obtained by summing the price multiplied by the quantity at the time of creation of the new product object.
Use a static class variable to store the total sum of products.

---

### Task 2
Using static variables and methods, add methods to the created class of products that return all the information about the products that cost the most and the least.

---

### Task 3
Add a method to the created class of products to apply a given discount to all products when calculating the price.

---

### Task 4
A rectangle in the plane can be described by two points, which are the coordinates of the diagonal angles.
Create two classes - Point and Rectangle.
The Point class will describe the coordinates (x and y) of a point in the plane, while the Rectangle class will have two Point objects.
Create methods in the class to calculate the perimeter and the area of the rectangle.
All rectangles have one common point.
Create an array of rectangles (with rectangles of different sizes) and output their area and perimeter values.
Change the coordinates of the common point of all the rectangles and again output the area and perimeter values.

---

### Task 5
Create a coffee machine class with 5 coffee names and prices. Create static methods in that class that:
* output a list of drinks with their corresponding prices;
* allow to select the coffee;
* allow to buy the selected drink (enter the amount of money that has been dropped into the machine);
* check whether the amount of money entered is sufficient to buy the selected drink and if it is sufficient to calculate the change in the corresponding coins;
