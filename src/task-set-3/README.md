# Task Set 3: Class Composition

### Task 1
A rectangle in a plane can be described by four points, which define the coordinates of its corners.
Create two classes – Point and Rectangle.
The Point class describes the coordinates of a point in the plane (x and y), and Rectangle will have four objects of the Point class, which will define the coordinates of its corners.
Create methods of the class that would allow calculating the perimeter and area of ​​a rectangle based on the entered coordinates of its corners.
