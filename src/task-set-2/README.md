# Task Set 2: Objects and Classes

# Task 1
Create a class Employee, which contains public data about the employee's age, work experience (in years) and salary.
In the main function, create an object of that class, enter the data and display all information about the employee to the screen.

---

### Task 2

### Task 3
In the previously created class, create 2 methods that calculate and display how much the employee pays in taxes from the salary (respectively, income tax 15% and Social Security 9%).
In the main function, create an object of that class, enter the data and display all information about the employee to the screen.

---

### Task 4

### Task 5
Create a class GeometricFigure, which describes the variables of a two-dimensional geometric figure: the number of edges and regularity (yes/no).
Create two constructors and methods for assigning and returning data.
In the main function, create an object of that class, enter the data and display all information on the screen.

### Task 6
Create a class Student, which stores the student's semester data: name, surname, credits for 5 semester subjects (number from 3 to 6) and grades (from 0 to 10).
Create a method in the class that calculates and returns the student's semester average:

```
average=(credit1*grade1+credit2*grade2+...+credit5*grade5)/(credit1+credit2+...+credit5)
```
In the main function, create an object of that class, enter the data and display all information on the screen.
