# Task Set 9: Standard Template Library

### Task 1
Write a program that converts an entered decimal number to binary.
Use the stack data structure to perform the task.

---

### Task 2
A sequence of numbers is entered using the keyboard.
When a new number is entered, the average of the last five entered numbers is calculated, and the last 4 calculated averages are displayed on the screen.
Choose the most appropriate data structure to perform the task.

---

### Task 3
Write a program that will implement a weekly work calendar.
For example, entering the word "Thursday" should output "Walk the dog", "Go to lectures" "Complete programming tasks".
The program should also have the ability to add a new activity to the corresponding day and the ability to remove an activity.
